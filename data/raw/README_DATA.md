# Raw data notes

All CSVs in this folder use `|` as the delimiter. Files ending `_seed.csv` are initial raw records assembled from publicly indexed Samfya Town Council pages/documents so that Person B can start immediately. They are not the final cleaned dataset.

Blank fields mean the indexed source did not expose that value in the available listing; do not invent them. The live scraper should discover direct document links when run on a normal internet-connected PC.
